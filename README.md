## Mô tả hệ thống
Hệ thống hỗ trợ quản lý thông tin thiết bị phòng học, theo dõi tình trạng sử dụng và cập nhật thông tin thiết bị.

## Công nghệ sử dụng
- Frontend: React
- Backend: Node.js, Express
- Cơ sở dữ liệu: MongoDB Atlas
- Quản lý mã nguồn: Git, GitHub
- Đóng gói & Triển khai: Docker, Docker Hub, Render
